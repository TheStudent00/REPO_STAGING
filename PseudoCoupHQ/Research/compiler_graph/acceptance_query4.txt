# ------------------------------- CAVEAT (read before any result) -------------
# The movement edges OVER-APPROXIMATE, in four named ways.
#
#  1. OBJECT-INSENSITIVE.  Field-sensitive (which field f is matters),
#     object-insensitive (which x holds f does not).  A store into a.f reaches
#     every read of .f anywhere in the parsed region, b.f included.  Wherever a
#     path below crosses a field node, that hop carries this looseness.
#  2. FLOW-INSENSITIVE.  Statement order inside a function is not modelled.
#  3. DISPATCH.  Call binding re-uses the map's own call edges, candidate sets
#     included, so an argument binds to the matching parameter of EVERY
#     candidate callee.
#  4. THE CALL NODE IS A PASS-THROUGH.  An argument flows INTO a call node and
#     the call's result flows OUT of it, so a two-line walk through a call node
#     will carry any argument to any result.  Leg 2 below therefore refuses to
#     use that shortcut and goes through the callee's BODY instead.
#
# Therefore every path here is a BOUND OVER ALL RUNS: it says these hops exist
# in the compiler's source and are joined forwards.  It does NOT say any single
# compilation took them.  The diary (per-run fact, subject column) and the arch
# campaign's forced probe stay the judges; the diary cross-check is at the end.
