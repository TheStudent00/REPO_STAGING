## definition

`run(model, langs) -> Dictionary`

Input: the model at a commit and the languages. Output: the dictionary.

Steps, in order:

1. `defs = model.definitions()`
2. for every language, for every unit in its corpus: `unit.lean = unit.meaning(defs)`
3. `pass_a_find`; `pass_b_build`; `pass_c_units_across_languages`
4. return the dictionary, with every refusal as a row
