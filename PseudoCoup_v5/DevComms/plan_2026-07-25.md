## Where we stand

  → CLIF → ISLE lowering → Rust's own encoder → x86-64 bytes → mmap →
  executed in stock CPython. 81-row grid **byte-identical to native
  rustc**.
- `.pc` hub modules with real qualified operators (`a r./ b`), zero

- Tier A transpiler: Cranelift's 1071 generated encoders → Python,

**Measured, not guessed**

- LLVM `X86GenDAGISel.inc`: 375,884 lines, ~99.5% one opaque
  `MatcherTable[]` consumed by a hand-written VM. Not transpilable by
  the 1:1-function strategy.

- **Pointers are not a barrier**: across `X86MCCodeEmitter.cpp`,
  `SelectionDAGISel.cpp`, `X86ISelDAGToDAG.cpp` — zero
  pointer-expression derefs, zero `memcpy`/`memset`/`reinterpret_cast`.
  Every flagged "pointer arithmetic" site is an integer counter
  (`CurOp++`). Every `->` is object navigation, free in Python.

## The strategic picture

Cranelift was a **quarry, not a dependency**. `pc_vocab/` is extracted,
version-pinned, and calls nothing at run-time. What it encodes is the
**ISA, not Cranelift's opinion** — verified by LLVM's REX line being
character-identical and gcc's div/rem/mul bytes matching verbatim.
Nothing needs abandoning; there is no ongoing Cranelift dependency to
carry.

LLVM matters for three things we do not have: **more architectures**,
**optimization quality**, **industry alignment**. It does not matter
for x86-64 integer correctness, which is done and triple-verified.

The LLVM cost splits sharply:

| Piece | Difficulty | Why |
|---|---|---|
| encoder (`X86MCCodeEmitter.cpp`) | comparable to `rex.rs` | switches + bit arithmetic + counters; no templates, ~1 STL use, no memory model |
| instruction selector | expensive | 375k-line matcher table + hand-written VM + 210 hand-matched C++ cases |

**A second architecture needs the encoder. Optimization needs the
selector.** Price them separately; do not buy both to get one.

## Plan

### Phase 1 — close the Cranelift work (no new dependencies)

1. **Full-scale differential test.** All 1071 instructions: Rust
   `encode()` vs transpiled `encode()`, byte-compared, operands
   fuzzed. Turns "0 faults" into "0 differences."
   *Delegate to Sonnet.* Acceptance: a table of 1071 rows, all match,
   or a named list of divergences.
2. **Machine-transpile the support layer.** `vocab_support.py` is
   currently hand-written by Fable — the one hole in uniform
   automation reach. Build the second-grammar transpiler (arithmetic,
   `match`, struct literals, `impl` blocks) and regenerate it.
   Acceptance: regenerated support layer passes the existing
   `test_vocab.py` gate unchanged.
3. **Cut the two marked gaps**: `CheckedDivOrRemSeq` (needs
   branch/label encoding — a genuinely new encoder capability) and
   `udiv`/`urem`. Acceptance: the backend stops refusing divisor `-1`
   and unsigned ops; grid extends and still matches rustc.

Phase 1 makes the existing artifact complete and fully reproducible.
Nothing in it depends on the LLVM decision.

### Phase 2 — the C++ ingress transpiler

Target: `X86MCCodeEmitter.cpp` (2,033 lines).

Chosen because it is the **smallest real C++ artifact with a
verifiable output** — we can diff its bytes against our existing
rustc-verified vocabulary, instruction by instruction. It is a
measurement with a right answer, not a design exercise.

Node rules already known from measurement:
- `->` becomes `.` (object navigation, free)
- bit arithmetic on fixed-width ints → existing `u8()`/`u32()` polyfills
- `x++` in argument position → split into two statements,
  **guarded**: exactly one increment in the expression AND the
  parameter is by-value, else fail loudly (this is divergence class 3
  appearing inside our own tooling — measured zero violations in the
  target file, but the transpiler asserts rather than assumes)
- `switch` → if/elif chain
- cuts carry reachability invariants, asserted at the cut site

Acceptance: the C++-transpiled encoder produces bytes identical to
the Rust-transpiled encoder for every instruction both cover. Two
independent extractions of the same ISA facts agreeing is a strong
result — and it is the diverse-double-compiling discipline applied to
our own pipeline.

first** (its intentions are the most dominant), meaning a mapping to

## Standing rules (unchanged, restated)

- Uniform polyfill wrapping; no proof-as-exemption.
- Cuts carry reachability invariants and assert them.
- Measure, do not estimate. Numbers come from commands actually run.
- Emitted artifacts are the stability layer: deterministic, no
  timestamps, provenance in the header.
- Self-hosting acceptance, when it arrives: T1 output == T2 output.
