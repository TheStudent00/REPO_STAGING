# Application

Applying the Tools to specific goals. First application: Rust
(LLVM) transpiling and slicing — the intermediate project goal.

- Churn is expected here; this is where tools meet reality.
  Iteration mess lives here so Tools stays clean.
- One application, one folder, nested as needed; local `.archive/`
  for superseded work.
- What an application proves out as GENERAL graduates into Tools
  (meeting Tools' threshold: self-contained, falsifiable acceptance
  test, oracle assets alongside).
- Findings that change plans flow to Planning; open questions that
  need experiments flow to Research.
