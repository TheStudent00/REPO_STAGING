## definition

Integration of the JavaScript V8 Engine. We leverage V8's JIT compilation logs (via `--trace-turbo` and `--print-opt-code`) to formally trace AST nodes through their lowering phases down to exact machine instructions and register allocations. We auto-generate all JavaScript operator probes mechanically via `operator_arity.json` and use the diary/tracing concepts from the `compiler_graph` to prove argument identities, rather than guessing them.
