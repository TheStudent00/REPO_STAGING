## definition

The architecture the line was built on. Everything below is what
touches the machine; the shared part (terms, cells, bank, proofs)
lives above this node.

`lifter`
- `Research/op_pipeline/reference.py`: every attested `arch_opcode`
  (253 cells over 134 mnemonics; 162 mnemonics in the corpus
  vocabulary) as a z3 function per written place, flags included.

`level 0 check`
- the K-framework x86-64 semantics (Strata formulas) parsed to z3 and
  set beside the lifter, per opcode (`Research/oracle/arch_opcodes/level0/`).
  ref1 (2026-09-10) found four defects in the lifter; ref2 corrects
  them and re-derives the table, the term store, the pool and the bank
  (running).

`carve`, `calling convention`
- objdump at the function symbol; the System V ABI: rdi rsi rdx rcx r8
  r9 arrive, rax answers, xmm0 for floats; a narrow argument is read at
  its own width (the low bits of the register).
