## §1. What the objects are, one sentence each, in relation

- A **ledger row** is one entry of a canon40 unit's `ledger` list — one
  slot of the unit's virtual memory, holding one value the unit reads
  or writes, with its own `block` (which memory region: `IN TEMP OUT
  CONST GUARD OWN STACK X87`), `type` (a plain-words width/kind
  string), `size` (bytes), and `produced_by` (what wrote it).
- An **opcode occurrence** is one ledger row whose
  `produced_by.kind == "arch_opcode"` — the row IS one instance of its
  `produced_by.mnem` running, whatever else that unit's body also
  does. This is the population change from o9: o9 counted a unit ONLY
  when its whole body reduced to one such row; o10 counts every row,
  in bodies of any length.
- A **holder**, this task's own term for one operand or produced
  position's (class, width) pair, rendered `class|width_bytes` — the
  same string shape o9's holders use (`DW_ATE_signed|4`) so the two
  censuses' tables compare directly. An IN row's holder is read from
  `types101_entry_holders.json`'s per-unit `parameter_holders`
  (DWARF-classed); every other row's holder is read from its OWN
  `type` string (width only; class `unknown` unless the string names
  one — see §2's walkthrough for why, and what changes because of it).
- A **signature** is one (operand holders tuple → produced holder)
  pair attested by at least one opcode occurrence — the same shape o9
  used, over a much larger row population.
- The **262-signature table**, the **reading-kind table**, the
  **collapse count**, and the **five-pairing re-examination** are four
  renderings of the SAME join at four keys — the direct co-nodes of
  o9's own four renderings, over the fuller population.

the assembly read `%xmm1`'s prior bits even though the C source never
passed a third argument. **DECIDED**: `IN-i` maps to

list (this `IN-2`) is treated exactly like a non-IN row — own `type`,
class `unknown` — rather than guessed at. Checked directly before

IN row) came back empty on the full run, so no operand reference was
ever silently dropped.
