The forced probe — the proof layer, same in every language

Two programs differing only in operand order. Subtraction is not symmetric, so only one assignment of {a, b} to registers explains both outputs. This rests on a single assumption — the compiler compiled the program we wrote — and on no dump format at all.

What the walk proves, and what it warns

The chain is a real graph — nodes are files the compiler will emit on request, edges are name correspondences — but the captures show the edges are not equally trustworthy. Rust carried the name a all the way into its LLVM IR; C dropped it one stage earlier (%0, %1 — position survives, the name does not); Go refused to produce its middle-form dump at all in this run, and its DWARF matched runtime functions instead of ours; Swift's DWARF listed a register that contradicts its own assembly. Each dump is one tool's testimony in a private dialect. The forced probe is the only rung that behaved identically in all four languages — which is why the identity ledger is built on it, with testimony kept as cross-check.
